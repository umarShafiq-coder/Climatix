# 🌤️ Climatix

A modern and responsive weather application built with **React**, **Vite**, and **Material UI**. Climatix allows users to search for any city worldwide and instantly view live weather information through the OpenWeatherMap API.

---

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 🥶 Feels-like temperature
- 💧 Humidity information
- 📈 Minimum & Maximum temperature
- ☀️ Dynamic weather icons
- 🖼️ Weather-based background images
- 📱 Responsive Material UI interface
- ⚡ Fast performance powered by Vite

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Material UI
- CSS3
- OpenWeatherMap API

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Climatix.git
```

Navigate into the project

```bash
cd Climatix
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
